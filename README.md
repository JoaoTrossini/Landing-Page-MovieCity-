# Projeto React com Vite

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade prática do curso de Desenvolvimento de Sistemas do SENAI, com o objetivo de aplicar conhecimentos de desenvolvimento Front-End utilizando React e Vite.

## 💡 Conhecimentos abordados

- Criação e execução de projetos utilizando React com Vite.
- Estruturação de pastas e arquivos do projeto.
- Criação e reutilização de componentes.
- Carregamento e utilização de imagens.
- Desenvolvimento de interfaces responsivas.

## 🛠️ Tecnologias utilizadas

- React
- Vite
- JavaScript
- HTML5
- CSS3
- npm

## ⚙️ Como executar o projeto

**1.** Instale o [Node.js](https://nodejs.org/), caso ainda não esteja instalado.

**2.** Abra o terminal na pasta do projeto e instale as dependências:

```bash
npm install
```

**3.** Execute o projeto:

```bash
npm run dev
```

**4.** Acesse no navegador o endereço informado pelo Vite no terminal, geralmente `http://localhost:5173/`.
